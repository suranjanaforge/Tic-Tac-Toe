# ❌ Tic Tac Toe ⭕

Just had some free time, felt like making something fun, and ended up building Tic Tac Toe!

This is a simple little browser game made using HTML, CSS, and a bit of introductory JavaScript. Nothing too fancy — just the classic Xs and Os, a little styling, and some code to make it all work.

It was a fun way to experiment with JavaScript and see how a webpage can go from being static to actually responding to what you do.

## 🎮 What's in it?

- ❌⭕ **Classic Tic Tac Toe** — The good old Xs and Os.
- 🖱️ **Interactive Gameplay** — Click on a cell and make your move.
- 🏆 **Win Detection** — Check who gets three in a row.
- 🤝 **Draw Detection** — Because sometimes nobody wins!
- 🎨 **Simple UI** — A clean interface to keep the focus on the game.

## 🛠️ Made With

- **HTML** — The structure of the game.
- **CSS** — The styling and layout.
- **JavaScript** — The basic game logic and interactivity.

## 🚀 How to Run It

Want to give it a try?

1. Clone this repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
4. Start playing!

No complicated setup required. Just open it and play. 🎉
